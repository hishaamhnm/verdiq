
# 🌱 Verdiq – Carbon Credit Wallet System

Verdiq is a simple web application that allows users to earn carbon credits (CC) for eco-friendly actions like using public transport, recycling, walking, and saving energy.

These credits are stored in a personal wallet using Firebase and can be tracked in real time on a dashboard.

---

## 🚀 Features

- 🔐 User Signup & Login (Firebase Authentication)
- 💳 Personal Carbon Wallet (Firestore Database)
- 🌍 Earn credits for eco-friendly actions
- 📊 Live dashboard with real-time updates
- 💱 Credit to currency conversion system
  - 100 CC = 1 QAR
- 🔄 Instant data sync using Firebase

---

## ⚙️ Tech Stack

- HTML
- CSS

- Firebase Firestore

## 🧠 How It Works

1. Users sign up or log in using Firebase Auth  
2. A wallet is created in Firestore  
3. Users earn credits by clicking eco-action buttons  
4. Credits are stored in Firebase database  
5. Dashboard updates in real time  
6. Credits are converted into QAR value
